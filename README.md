# Rahul Nune

Developer in Melbourne.

I mostly work in JavaScript and TypeScript Node.js, PostgreSQL, Appsmith, and Cloudflare Workers. Lately I've been building health dashboards and small tools that connect to real APIs.

## Projects

**[Health Dashboard](https://github.com/nunerahul/health-dashboard)**
A dashboard for Apple Health data — activity, heart rate, sleep, and the rest — with charts and trends. The public version uses demo data.

**[AppSmith](https://github.com/nunerahul/AppSmith)**
A timesheet dashboard built with Appsmith and PostgreSQL. It tracks 14-day work cycles, shift hours, PAYG withholding, take-home pay, and leave.

**[whoop-proxy](https://github.com/nunerahul/whoop-proxy)**
A small Node.js proxy for the WHOOP API. Handles OAuth and the recovery, sleep, and cycle endpoints.
